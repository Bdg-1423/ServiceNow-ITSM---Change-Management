## ServiceNow-ITSM---Change-Management
ServiceNow Change Management helps organizations plan, assess, approve, implement, and track IT changes while minimizing risks, reducing service disruptions, and maintaining system stability.

## Project Overview
This hands-on project focuses on configuring and understanding the ServiceNow IT Service Management (ITSM) Change Management workflow to manage IT infrastructure and service changes in a structured, controlled, and efficient manner. The workflow helps reduce operational risks, minimize service disruptions, and ensure that changes are properly assessed, authorized, implemented, and reviewed.
The project covers the complete change lifecycle, including New, Assess, Authorize, Scheduled, Implement, Review, and Closed, with the option to cancel a change when necessary. It also explores the differences between Standard, Normal, and Emergency changes based on risk, urgency, approval requirements, and implementation complexity.
## Key Activities
• Created and managed change requests in ServiceNow.

• Documented change justification, implementation plans, risk and impact analysis, test plans, and backout plans.

• Evaluated change risks and potential effects on IT services.

• Reviewed authorization and approval requirements.

• Planned and scheduled changes to minimize service disruption.

• Followed implementation and post-implementation review procedures.

• Documented outcomes and completed the change closure process.

The above diagram compares the three main change types in ServiceNow Change Management based on priority, risk, approval requirements, and frequency.

- Standard Change: A low-risk, routine change that is pre-approved and performed frequently, such as a standard software installation.
- Normal Change: A planned change that requires risk assessment and approval before implementation, such as a server upgrade or network configuration change.
- Emergency Change: An urgent change needed to resolve critical incidents or restore services, such as fixing a major network outage. It follows an expedited approval process, often involving the Emergency Change Advisory Board (ECAB).

Key takeaway: ServiceNow uses these change types to ensure IT changes are properly assessed, approved, and implemented while minimizing risk and service disruptions.
